# 公司揪團後端設定（約 10 分鐘，只要做一次）

揪團的資料會存在你們自己的 Google 試算表，免費，也不會動到現在管休息日的 Apps Script。

## 1. 建立試算表
1. 到 Google 雲端硬碟 → 新增 → Google 試算表，命名為「FEEDO 揪團」。
2. 不用手動建立任何欄位，第一次有人揪團時會自動建立 `groups`、`entries` 兩個工作表。

## 2. 貼上程式碼
1. 在試算表上方選單點「擴充功能」→「Apps Script」。
2. 把編輯器裡原本的內容全部刪掉，貼上本資料夾 `group-order.gs` 的全部內容。
3. 按上方的「儲存」（磁碟圖示）。

## 3. 部署成網頁應用程式
1. 右上角「部署」→「新增部署作業」。
2. 左邊齒輪「選取類型」→「網頁應用程式」。
3. 設定：
   - 說明：`揪團`
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按「部署」，第一次會要求授權：選你的帳號 →「進階」→「前往（不安全）」→「允許」。
   （這是 Google 對自己寫的程式的標準提醒，程式只會讀寫這份試算表。）
5. 複製畫面上的「網頁應用程式網址」（結尾是 `/exec`）。

## 4. 接到網站
打開 `index.html`，搜尋 `GROUP_API`，把網址貼進引號裡：

```js
const GROUP_API = "https://script.google.com/macros/s/xxxxxxxx/exec";
```

上傳網站後，茶單上方就會出現「👥 公司揪團」按鈕（沒填網址時不會顯示）。

## 5. 開啟自動刪除（只要做一次）
隱私權說明寫的是「揪團截止日起 30 天後刪除」，由程式每天自動執行。
1. 確認編輯器裡已經是最新的 `group-order.gs`（有 `purgeExpired`、`installPurgeTrigger` 兩個函式），按「儲存」。
2. 上方函式選單選 `installPurgeTrigger` →「執行」。第一次會要求授權（多了「在你不在時執行」的權限），照畫面允許。
3. 左邊時鐘圖示「觸發條件」裡應該看到一個 `purgeExpired`、每天、上午 3 點的觸發器。

要改保存天數：改 `RETENTION_DAYS`，並同步修改官網的隱私權說明。

## 之後如果要改後端程式
「部署」→「管理部署作業」→ 鉛筆圖示 → 版本選「新版本」→「部署」。網址不會變，網站不用改。
（只改自動刪除的部分不用重新部署，觸發器會直接用儲存後的程式。）

## 資料說明
- `groups`：每一團。`admin` 是發起人的管理碼，請不要外流。
- `entries`：每個人的點單。`summary` 欄是給人看的品項文字，店家可以直接在試算表看。
- 截止超過 30 天的揪團與點單，每天凌晨 3 點自動整列刪除，不影響進行中的揪團。
